# 震迹——基于Agnes Harness的地震候选事件智能核查Agent

**让 AI 主动取证、调用专业分析工具，并在你改变条件后继续复核。**

震迹是一个本地可运行的震迹工作台：用户用自然语言提出一个具体的可判定问题（例如“这段观测能不能用来做 1–12 Hz 的 P/S 拾取？”），系统在指定的 UTC 时窗与台站范围内，由 AGH（Agnes Harness）承担核心组织、执行与工具调用，驱动模型选用业务工具真实取得公开观测、运行本地专业计算，再由确定性验证器检查模型交付是否与证据、范围与停止依据一致；用户修改条件后，系统生成一条关联父运行的新运行继续复核（默认复用已取得观测、不新增取数）。它区分“输入适用性”（通道/采样率/频带是否满足方法输入条件）与“到时诊断稳定性”（多配置自动到时是否可复现），并且不把失败或未知改写成成功。本作品不是地震预警或上线监测系统，不主张总体准确率或“Agent 优于规则”。

本文档的相对链接以本目录为基准；解压包根目录的 `README.md` 提供对应入口。

## 当前入口

- 启动脚本：`main/start.sh` → `main/server.py`（默认端口 **8791**，脚本需要 `/bin/zsh`；也可直接用 Python 启动）。
- 页面：启动后打开 `http://127.0.0.1:8791/`（仅本机回环访问）。
- 说明：工程根目录下的 `prototype/start.sh`（旧 8765 入口）属于早期原型，不是当前主入口。

```sh
# 1) 使用包内已保存记录启动主服务（默认 8791）
RUNLOG_DIR="$PWD/replay/runlog" EQ_STRICT_OFFLINE=1 ./main/start.sh

# 没有 /bin/zsh 时，用 Python 启动：
# RUNLOG_DIR="$PWD/replay/runlog" EQ_STRICT_OFFLINE=1 .venv/bin/python main/server.py 8791

# 2) 在浏览器打开 http://127.0.0.1:8791/
```

## 工作台（三视图）

页面为单页三视图，默认打开**核查工作台**并加载已验收真实示例（只读回放，不调用模型）：

- **核查工作台**：左侧任务与当前条件；右侧结论与状态、**同 run 真实波形**（读已落盘 MiniSEED，画 Z/N/E 三分量 min/max 包络，到时标记只来自该 run 的实际结果）、**AGH 真实工具时间线**（模型实际调用的 MCP 工具，系统条件守卫单独标注）、**改条件再复核**与首轮→改动→当前三列对比。
- **核查记录**：来自持久 run 目录的列表（问题、父子关系、状态、来源、费用），点一行在工作台打开；失败记录保留。
- **使用说明**：问题背景、三项能力、方法原理与使用步骤、示例的统计范围、数据来源。

状态区分：复核完成 / 复核完成·当前证据不足（合法未知）/ 已使用规则后备 / 本轮执行失败；已有真实核查记录通过只读方式展示。加载、切换记录、切换视图与“确认条件（免费）”都不调用模型。

## 无 Key 回放已验收示例（不花模型费）

回放只读取包内 `replay/runlog/` 中已保存的真实核查记录，不调用模型、不新增取数、不需要模型 Key。必须按快速开始设置 `RUNLOG_DIR`，以免服务使用默认的空记录目录。启动服务后：

```sh
# 列出运行记录
curl -s http://127.0.0.1:8791/api/runs | python -m json.tool | head

# 读取首轮 r-e2e8419bf299785d 的完整证据（结论/范围/条件/工具调用/费用/清理）
curl -s http://127.0.0.1:8791/api/evidence/r-e2e8419bf299785d | python -m json.tool | head -40

# 读取条件反馈 r-3ae9c6948c2f8967
curl -s http://127.0.0.1:8791/api/evidence/r-3ae9c6948c2f8967 | python -m json.tool | head -40

# 读取该 run 某候选的真实波形（只读已落盘文件）
curl -s http://127.0.0.1:8791/api/waveform/r-e2e8419bf299785d/409dfad13970 | python -m json.tool | head -20
```

已验收示例为真实父子链：首轮 `r-e2e8419bf299785d` → 反馈 `r-3ae9c6948c2f8967`。费用上界：首轮 0.100140 元，反馈 0.081032 元，本链合计 0.181172 元；2026-10-12 的研发机累计台账快照为 17.464664/20 元，当前金额以实时台账为准。只有提交新的智能核查或智能反馈才会调用模型、产生费用。

## 可选：真实执行（会消耗预算）

填写核查条件后可直接点击“开始智能核查（计费）”或“开始标准核查（免费）”，系统自动免费检查输入；“确认条件（免费）”是可选步骤，不获取观测。查看示例、浏览核查记录均免费；只有提交智能核查或智能反馈才会调用模型。标准核查使用同一组输入条件，不调用模型，但可能获取公开观测。真实执行需要本机存在未被版本控制的模型 Key 文件（`../deepseek_model.txt`，**不随作品提交、不写入任何截图或公开内容**），并遵守每次请求的预算预留/结算守卫。2026-10-12 的研发机累计费用上界快照为 17.464664 元，硬守卫上限 20 元；不要将历史快照当作当前剩余额度。
