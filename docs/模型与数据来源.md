# 模型与数据来源

## 模型与 AGH

| 项目 | 名称与版本 | 作用与调用方式 |
| --- | --- | --- |
| 运行模型 | DeepSeek `deepseek-flash`；配置记录的版本名称为 `DeepSeek-V4.1-Flash` | 参与首次核查与条件反馈，选择 MCP 工具、检查证据并提出结论；通过本地桥接调用 DeepSeek Chat Completions 接口 |
| 执行框架 | Agnes Harness；源码提交 `349309a719b7a16462b9f3ebcf923683f8de5365` | 承担核心会话组织、连续执行、工具调用与异常处理；源码位于 `vendor/agnes-harness/`，许可证为 Apache-2.0 |

模型与工具执行配置随每条记录保存在 `agent_config.json` 和 `prompt_binding.json`。真实核查使用 DeepSeek 模型；Agnes Harness 是执行框架。

```text
AGH 会话 → 本地模型桥接 → DeepSeek API
       ↘ MCP 专业工具 → 波形分析与证据验证
```

模型服务来源：[DeepSeek API](https://api.deepseek.com)。AGH 来源：[AgnesAI-Labs/agnes-harness](https://github.com/AgnesAI-Labs/agnes-harness)。源码版本记录见 `evidence/agh/commit.json`。

## 观测与事件来源

| 来源 | 使用方式 | 对应材料 |
| --- | --- | --- |
| [EarthScope FDSN](https://service.earthscope.org/) | 通过波形和台站服务取得 MiniSEED、StationXML，读取采样率、通道和观测完整性 | `replay/runlog/r-e2e8419bf299785d/mcp_state.json` 及 `raw/` 观测文件 |
| [USGS / ANSS ComCat](https://earthquake.usgs.gov/data/comcat/) | 提供事件目录信息，用于工作台真实事件样例 `uw61900332` | `main/samples.py` |

保存的核查观测为 UW.CHIMA，时窗 2023-12-24T10:00:00–10:02:00 UTC，通道 ENE/ENN/ENZ。事件目录样例 `uw61900332` 与这条保存观测属于不同样例，分别用于说明来源与使用方法。

原始观测文件与记录中的 SHA-256 用于核对来源和内容一致性。数据的使用与再分发应遵循数据提供方的许可及署名要求。
