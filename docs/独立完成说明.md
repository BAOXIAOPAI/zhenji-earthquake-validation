## 工具与第三方来源

项目使用 OpenAI Codex 辅助代码与文档编写、修改和检查。作品运行由 Agnes Harness 组织任务及工具执行，实际核查模型为 DeepSeek `deepseek-flash`。公开观测来自 EarthScope FDSN，事件目录样例来自 USGS / ANSS ComCat；数值与接口组件见[模型与数据来源](./模型与数据来源.md)。

真实运行记录、规则测试与受控执行测试分别注明来源。项目说明保留证据不足、模型结论被拒和执行失败等结果，不以受控测试代替真实模型任务。
