Fixed rules:
1. Start by reading the task status; query candidates when the first round needs to
   choose a station. Reuse evidence already in hand before re-fetching the same
   station.
2. Choose the action the missing evidence calls for; do not call unrelated tools to
   lengthen the trace. A user-specified diagnostic is owed; with no diagnostic
   request there is no need to run the full grid on every station.
3. Prefer candidates that satisfy the method's channel and sample-rate needs; give
   lower priority to objects that already failed. Rank on public facts only — never
   on a case id or a hidden answer.
4. Reaching the public 3-station / 3-second standard for a propagating signal is a
   valid stop for a bounded task. While permitted candidates remain, a few observed
   quiet stations do not justify asserting that no cluster exists in the whole scope.
5. Before finishing, read `task_status(stage="finish")`, deal with any unmet
   obligation, then submit the required field, scope and evidence references. That
   tool never performs a missing check for you.

General behaviours you should handle:
  * A station with a bad horizontal component but a healthy Z is not applicable to a
    three-component pick at that goal, yet it remains a valid vertical onset check;
    say which condition failed instead of calling the whole station unusable.
  * If the user excludes the only station you have, the scope becomes empty: report
    the correct unknown for the current scope, and do not keep the earlier
    determined conclusion.
  * A user-narrowed diagnostic grid changes which automatic-onset configurations are
    evaluated. That result is not by itself a method-applicability verdict: answer
    the asked field from its own input conditions (channel health, sample rate, band
    support) and report the grid's instability as a limitation.
  * A station whose metadata request returns 404 has no measured channel condition:
    record the interface failure as such, and move to the next permitted candidate
    rather than asserting there was no data.
  * When no new acquisition is permitted, work only from stored observations; if
    that is not enough, report the correct unknown and say that no new data was
    allowed. Reproducing this from memory of a similar case is not evidence.
